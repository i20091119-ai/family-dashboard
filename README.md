# 우리 가족 화면 (거실 가족 대시보드)

거실 태블릿(가로)과 엄마·아빠 폰(세로)에서 같은 주소로 여는 가족 화면입니다.
설계: 「거실 가족 대시보드 설계」 문서. 포켓퀴즈 규칙은 「포켓몬 배움 탐험대 설계 정리」의 「전체 규칙 (11.20)」 탭.

## 화면

| 시간 | 화면 |
|---|---|
| 평일 07:30–08:30 | 🌅 아침 출발 도우미: 07:30에 시작하는 시간 막대 + 08:15 밥 / 08:20 세수·양치 / 08:25 옷·머리·로션 / 08:28 가방 메고 현관. 서준 줄(파트너 포켓몬 그림), 하준 줄(그림 버튼 5개). 누른 시각을 기록하고, 한 번 더 누르면 취소 |
| 17:00–22:00 | 🏡 홈: 시계·날짜·날씨(창원 중동) / 포켓몬 마을(보기만) / 버튼 4개 팝업(30초 뒤 닫힘) / 오른쪽 아래 늘 떠 있는 "오늘 일정"(누르면 가족 일정). 서준 훈련 진행은 "서준이 집" 창에서 |
| 그 외 | 어두운 화면. 터치하면 1분 동안 홈 |

- 가족 일정은 창에서 직접 적습니다(누가 적었는지 얼굴 버튼, 누구 일정인지 사람별 색: 아빠 초록·엄마 분홍·서준 빨강·하준 노랑·가족 파랑). 네이버 캘린더는 다음 단계에서 같은 카드에 더합니다. 하준이 집은 미리보기(기록 없음).
- 할 일·장보기는 로그인 없이 얼굴 버튼(엄마·아빠·외할머니)을 누르고 적거나 체크합니다.
- ⚙️ 설정: 등교 기록, 아침 기록(2주 비교), 등교 알림 받는 주소, 포켓퀴즈 연결, 가족 접속 코드, 개발 메뉴(이 기기만 날짜·시각 바꾸기).

## 포켓퀴즈 연결 (읽기만)

포켓퀴즈의 `docs/family-api.md` 창구만 씁니다. 포켓퀴즈 기록 저장소는 직접 건드리지 않습니다.
- 읽기: `GET /api/family` (파트너·일일미션·훈련·마을 지도·손님·등교) — 45초마다
- 보내기: `POST /api/family/events` `{type:"onTimeArrival", date, time}` 하나뿐 (판정·편지는 포켓퀴즈가 함)
- 마을 그림 파일은 포켓퀴즈 사이트에서 바로 불러오고, 그림 조각 자리 `src/shared/village-assets.json`은 포켓퀴즈 `lib/data/village-assets.json`을 복사한 것입니다. 포켓퀴즈에서 그림판이 바뀌면 이 파일도 다시 복사합니다.

## 등교 알림 (엄마 폰 MacroDroid)

⚙️ 설정의 "등교 알림 받는 주소"로 아이알리미 알림 글을 보내면(`POST /hook/alimi?k=…`, 본문 = 알림 글),
"등교"가 든 것만 글 속 날짜·시각(`11/19 08:46`)을 꺼내 포켓퀴즈로 보냅니다. 하교는 건너뜁니다. 알림 원문은 저장하지 않습니다.
포켓퀴즈에 연결이 안 되면 5분마다 다시 보냅니다(14일 안). 이번 주 평일이 지났는데 등교 기록이 0건이면 ⚙️에 빨간 점과 경고.

## 만들기·올리기

- 서버: `src/worker/` (Cloudflare Worker), 화면: `src/client/` → `npm run build`가 `public/app.js`로 묶음, 같이 쓰는 계산: `src/shared/`
- 기록 저장소(D1): `migrations/` (추가만, 지우기 금지)
- 검사: `npm run typecheck`, `npm test`
- 저장해서 GitHub에 올리면 `.github/workflows/deploy.yml`이 자동으로 올립니다. `main` = 진짜(`family-dashboard`), 그 밖 = 미리보기(`family-dashboard-preview`, 기록 저장소 따로).
  GitHub 저장소 Secrets에 `CLOUDFLARE_API_TOKEN`(포켓퀴즈와 같은 것)이 있어야 합니다.
- 처음 열면 가족 접속 코드를 정하는 화면이 나옵니다(그 뒤로는 ⚙️에서 바꿈).

## 올리기가 "Authorization header" 오류로 멈출 때

GitHub 저장소 Secrets 의 `CLOUDFLARE_API_TOKEN` 칸에 토큰 글자 한 줄만 있어야 합니다(이름·설명·빈 줄 없이).
열쇠를 바꾼 뒤에는 자동으로 다시 돌지 않으니, 새로 저장해서 올리거나 Actions 화면에서 "Re-run all jobs"를 누릅니다.
토큰 권한(Cloudflare → Profile → API Tokens → Edit): All accounts · Workers Scripts Edit · D1 Edit · Account Settings Read.
